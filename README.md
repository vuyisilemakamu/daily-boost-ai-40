# Your AI Co-Pilot

I've built the complete AI Workplace Productivity Assistant — a single integrated platform with no sign-in required, opening directly to the dashboard. Here's what's included:

Dashboard — A welcome hero with quick-action buttons, live stats (today's tasks, overdue, upcoming, completed), clickable AI tool cards, today's task list, upcoming deadlines with countdown badges, and recently completed tasks.

Smart Email Generator — Describe what you want to say, pick from 8 email types, 6 tones, and 3 lengths. It generates a subject line and body, which you can edit inline, copy, regenerate, or clear. There's also an "Improve/Rewrite" mode that cleans up and re-tones an existing email. A one-click example gets you started instantly.

AI Notes Summarizer — Paste long meeting notes and choose Brief, Standard, or Detailed. It extracts a concise summary, key points, decisions made, action items, deadlines, and important topics using a text-scoring algorithm. Everything is editable and copyable, with a realistic demo loaded in one click.

AI Task Planner & Scheduler — Add tasks with name, description, priority, deadline, and duration. The AI automatically breaks each task into logical steps and detects urgency from your wording. You can mark tasks/steps complete, edit, delete, reschedule inline, and reorder with up/down arrows. Overdue, today, and high-priority tasks are highlighted with colored borders. The AI Plan My Day feature builds an optimized timeline, and Plan My Week distributes tasks across a 7-day calendar grid. Tasks persist in your browser between visits.

Design — Clean sidebar navigation, modern cards, Inter typography, a blue-based color system, smooth fade/scale animations, loading skeletons, toast notifications, and full light/dark mode with a toggle. Everything is responsive from mobile to desktop.

The project builds and passes type checking cleanly. I couldn't launch the browser to test the live UI since the dev server is managed by the environment — if you spot anything that looks off when you open it, let me know and I'll fix it.
